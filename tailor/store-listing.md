## Name (45 char max)
Tailor – AI CV & Cover Letter for LinkedIn

## Short Description (132 char max)
Tailor your CV and cover letter to any LinkedIn job in one click. Uses your LLM API key. Private and affordable.

## Detailed Description

Stop sending the same generic CV to every job. Tailor reads your LinkedIn profile once, then generates a tailored CV and cover letter for any LinkedIn job listing — in seconds.

HOW IT WORKS
1. Add your LinkedIn profile URL and LLM API key (one-time setup)
2. Browse LinkedIn jobs as normal
3. Click the Tailor icon on any job listing
4. Get a tailored CV and cover letter, formatted and ready to download

WHY TAILOR?
- One-click tailoring — no copy-pasting job descriptions into chat tools
- Professionally formatted downloads — open in Word, Google Docs, or print to PDF
- Privacy-first — your API key and data stay on your device, never on our servers
- Affordable — uses your own LLM API key, roughly £0.01–0.03 per application
- Fast — CV and cover letter generated in parallel

YOUR DATA STAYS YOURS
Tailor stores everything locally on your device. The only external call is to your selected LLM provider API (using your key) when you generate an application. No analytics, no tracking, no accounts.

GETTING STARTED
You'll need an LLM API key from your provider (Anthropic, OpenAI, Mistral, Groq, or Cohere). Tailor handles the rest.

Built for job seekers who want to stand out without spending hours rewriting their CV for every application.
