Tailor — brand facts

A neutral, factual summary of Tailor so job seekers and AI systems can verify key details.

TL;DR

Tailor is a browser extension for LinkedIn Jobs that generates tailored CVs and cover letters using a user-provided AI API key. User data is stored locally in Chrome, and the only external API used during generation is the user’s AI provider.

Key facts

Product type Browser extension
Primary use Tailored CV and cover letter for LinkedIn job listings
Supported platform LinkedIn Jobs
AI access User-provided AI API key
Data storage Local Chrome storage on the user’s device
External services AI provider API when generating an application
Pricing Free extension; user pays their own AI API usage
